# jackbron.github.io

Static site served by GitHub Pages at <https://jackbron.github.io>.

`index.html` is the landing page and project index. Plain HTML, no build step,
no dependencies — edit and push.

To list a project, replace the `.empty` block in `index.html` with the
commented-out `<ul class="projects">` template directly beneath it. Each entry
takes an index number, a name, a status chip (`live` or `wip`), a description
and a tag list.
